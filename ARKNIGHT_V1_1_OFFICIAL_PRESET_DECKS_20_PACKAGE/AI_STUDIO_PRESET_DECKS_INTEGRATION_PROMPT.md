# Google AI Studio：接入 Arknight V1.1 官方预设卡组（20张）

请在现有 Arknight 项目中接入 `ARKNIGHT_V1_1_OFFICIAL_PRESET_DECKS_20.json`，CSV仅用于审阅与数据核对。

## 已确认规则
- 每套牌库固定20张卡牌副本。
- 同名卡在一套牌库中最多2张。
- 卡牌费用读取V1.1主卡池的 `command_cost_cp`，不得在预设数据里建立第二套费用来源。

## 本批预设的建议配比（不是全局构筑限制）
- 13张干员、5张战术、2张支援；支援再分为1设施、1装备。
- 这只是本批官方预设卡组的统一教学/平衡配比。除非项目已有对应规则或产品负责人另行确认，不得把类别比例硬编码为所有用户卡组的合法性限制。

## 执行步骤
1. 先审计项目实际 Deck/DeckList/DeckBuilder schema、卡组存储结构、卡牌主键、收藏与拥有数量逻辑、牌组编辑入口和验证函数。先报告文件路径与规则，再改代码。
2. 将JSON中的 `cardId`、`count` 映射为项目真实schema。所有ID必须存在；每套展开后必须恰好20张；同一cardId/同名卡不得超过2张。
3. 预设作为官方模板展示，不得覆盖用户已有卡组、修改收藏数量，或错误地把模板牌当作玩家已拥有的卡。允许玩家预览、使用预设或复制后编辑，具体沿用项目现有产品流程。
4. 在预设列表展示名称、玩法定位、难度、卡组数量、费用曲线、优势、弱点和简短打法。
5. 经典3路为本批预设的首要平衡环境。自定义1～5路仍使用固定卡牌效果，不得按棋盘尺寸自动增强卡牌；可以显示“自定义模式尚未单独平衡”的提示。
6. 增加自动化校验：20张总数、同名上限2、卡牌ID存在、类型分布仅用于预设展示、费用与主卡池一致；同时测试导入、保存、读取、编辑副本和切换预设不会破坏用户数据。
7. 先完成数据接入和UI展示，再运行测试。不要擅自修改卡牌数值、卡牌效果、CP曲线或规则文本来迁就预设卡组。
8. 最终输出变更文件清单、每套卡组导入结果、测试结果、未完成事项。没有运行的测试必须写“未运行”，不要声称通过。
